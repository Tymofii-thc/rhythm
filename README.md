# Ритм

Особистий трекер звичок для щоденної рутини: один файл `index.html`, чистий HTML/CSS/JS, без бекенду і залежностей. Дані зберігаються в `localStorage` браузера (ключ `ryt-v1`), тож лишаються тільки на вашому пристрої. Роби експорт у вкладці «Дані».

## Як змінити план

Відредагуй блок `PLAN` на початку скрипта в `index.html` і запуш у `main`. GitHub Pages оновиться за хвилину.
