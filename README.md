# Ритм

Особистий трекер звичок для щоденної рутини: один файл `index.html`, чистий HTML/CSS/JS, без бекенду і залежностей. Дані (галочки, нотатки, події) зберігаються в `localStorage` браузера (ключ `ryt-v1`) і лишаються тільки на пристрої. Роби експорт у вкладці «Дані»: якщо експорту не було понад 7 днів, застосунок нагадує на вкладці «Сьогодні». Імпорт перевіряє файл, показує, що зміниться, і зберігає копію поточних даних (її можна повернути у «Даних»). Застосунок можна встановити (PWA) і він працює офлайн.

План дня зашифрований (AES-256-GCM, ключ з парольної фрази) і розшифровується в браузері після введення фрази. Джерело плану й скрипт збірки зберігаються приватно, поза репозиторієм.
